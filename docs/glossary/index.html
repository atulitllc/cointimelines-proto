Glossary

Crypto glossary

Every term links to the moments in history where it mattered.

Halving

A halving is a scheduled cut in the new coins miners earn per block. Bitcoin halves every 210,000 blocks, about every four years.

Hard fork

A hard fork is a rule change that old software rejects, which can split a blockchain into two.

Soft fork

A soft fork tightens a blockchain's rules in a way older nodes still accept.

Proof of work

Proof of work secures a blockchain by making miners spend computing power to add blocks.

Proof of stake

Proof of stake secures a blockchain with validators who lock up coins as collateral.

Security (in crypto law)

In US law, a token sale can be a securities offering if buyers invest expecting profits from others' efforts.
