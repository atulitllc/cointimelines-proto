Data sources and methods

Every price on this site is a daily close (UTC) taken from a free, public exchange API at build time on Oct 14, 2026. We use one exchange per day, preferring the earliest continuous USD market for each coin, and fill earlier days from Binance USDT pairs only where no USD series was available. Each price shows the exchange, pair and date it came from. When our data does not cover a date, we show no price rather than an estimate.

Event facts are written in our own words and link to primary sources such as whitepapers, BIPs and EIPs, SEC filings, court dockets, official project blogs and block explorers, plus Wikipedia for background.
